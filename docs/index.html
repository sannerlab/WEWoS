WEWoS

Vision, the visual programming environment of MGLTools, in a web browser.

The idea

A network is a set of nodes, each running a small Python function, joined by connections that carry data from an output port to an input port. Data flows from left to right: a node's inputs are on its left edge, its outputs on its right edge. When a node gets new data it runs and sends its results on; that is all a program is.

Building a network

  • Drag a node from the palette on the left onto the canvas (or double-click it in the palette).
  • Drag from an output port to an input port to connect them. Ports that can take the data light up.
  • Inputs with a widget (a number, a text, a file name...) show it in the node or in the parameter column on the right. To connect such an input instead, right-click its widget (in the node or the panel) and choose Unbind (show the port), or click unbind in the panel's list of ports; the input becomes a port you can connect. Right-click that port and choose Rebind widget to get the widget back.
  • Scroll over a number (mouse wheel, or two fingers on a trackpad) to change it step by step; Shift makes the steps 10 times finer, Alt/Option 10 times coarser. Dragging the ⇄ handle changes it continuously.
  • Shift-drag on the canvas selects several nodes; Delete deletes, Ctrl-C/Ctrl-V copy and paste, f fits the network in view; the mouse wheel zooms and dragging the background pans.

Running

Runruns the nodes that have new data, and the nodes below them (Vision's run)
Run allruns every node
run on changewhen checked, changing a widget or a connection runs what it affects
Pause / Stopact between nodes; a node that is running finishes

A node that fails is outlined in red; select it to read the error. Anything nodes print goes to the Log.

Writing nodes

Every node's computation is Python you can edit (Edit code…, or double-click the node):

def doit(self, x, k):
    self.outputData(y=x * k)

The arguments are the input ports in order; self.outputData(port=value) sends results. Start from a Generic node, add ports with Add a port in the panel, and write its code. Returning 'Stop' stops the nodes below.

Macros

Select nodes and choose Group into a macro: they become one node whose inside opens in a tab (double-click it). Inside, connecting to port new of the input or output node adds a port to the macro.

3D

A Viewer node opens a 3D panel in the row under the network (image panels go there too, from left to right; drag the divider above the row to make it taller), drawn with 3Dmol.js or Mol* (the menu in its header; Mol* adds ambient occlusion, shadows, depth of field and illumination). Connect geometries to its geometries input: Spheres, Cylinders, IndPolygons (meshes), lines, labels, and from the Molecules library CPK, Sticks, Lines, Cartoon, Surface and MSMS. A Color Map node turns values into colors; its parameter panel has Vision's color map editor: draw the ramp's channels (RGB, HSV or HSL, and opacity) as curves with the mouse (left button freehand, Shift-click a straight segment from the last point, right button a straight line), pick a preset, set min and max, undo (Ctrl/Cmd+Z) or reset, and read or write Vision colormap files. Click something in the viewer: the Viewer's lastPick output sends it to the nodes connected there (try Picked Atom, or the example pick a residue).

Files

Networks are saved as .wnet.json in the network's folder (File > Save), and opened with File > Open network. Vision's *_net.py files are imported with File > Import a Vision network; the file is read, never executed, and a report lists any node that has no counterpart here (those stay in the network, outlined in red, with their ports and code).

History

Vision began as ViPEr, a Visual Programming Environment for Python, by Michel Sanner, Daniel Stoffler and Arthur Olson (Molecular Graphics Lab, The Scripps Research Institute). It was presented at the 10th International Python Conference in February 2002, where it received the best paper award: M. F. Sanner, D. Stoffler, A. J. Olson, ViPEr, a Visual Programming Environment for Python. It was later renamed Vision, because of a name conflict at Scripps with VIPER, the Virus Particle Explorer of Charles Brooks's lab, and distributed with MGLTools. WEWoS keeps its design and reads its networks.
